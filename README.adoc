= AI-Driven Network Remediation Showroom

Draft hands-on workshop for the AI-Driven Network Remediation quickstart.
The walkthrough covers Network investigation, remediation, and escalation, followed by RAN anomaly detection and root-cause analysis.

== Read the workshop

Start at link:content/modules/ROOT/pages/index.adoc[the welcome page].
The eight modules follow the sequence in link:content/modules/ROOT/nav.adoc[the navigation].

The profile uses one OpenShift cluster, a tenant application namespace, and a tenant-specific edge namespace.
Both RAN predictors run locally on CPU.
LLM inference uses real external MaaS.
AAP execution and Network ServiceNow tickets use tenant mocks.

== Build locally

From this repository root, install the same Antora components used by the existing workflow into an ignored tools directory:

[source,shell]
----
npm install --prefix .cache/antora-tools --cache .cache/npm --no-audit --no-fund \
  @antora/cli@3.1 @antora/site-generator@3.1 \
  @sntke/antora-mermaid-extension@0.0.13 @andrew-jones/antora-tabs-extension
NODE_PATH="$PWD/.cache/antora-tools/node_modules" \
  .cache/antora-tools/node_modules/.bin/antora --clean --log-failure-level warn site.yml
----

The output is in `www/`.
The initial build needs network access for dependencies and the UI bundle.
Preview builds intentionally show namespace placeholders until provisioning supplies the assigned tenant attributes.
The original template's authoring examples remain in `examples/`; template developer-guide pages were removed from the learner site.
